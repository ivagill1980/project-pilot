# Session log

One dated entry per session, appended as the session ends. The log is read back every few
sessions, or as soon as a complaint starts to feel familiar: a second occurrence is the
signal to promote it into a rule, a script, or a gate.

## Promotion rules

- A behavioral rule that keeps being restated → durable instruction.
- A project fact → reference documentation.
- A recurring quality correction → a script, hook, or gate.
- A repeated procedure → automation.
- Anything local to one incident stays in this log.
